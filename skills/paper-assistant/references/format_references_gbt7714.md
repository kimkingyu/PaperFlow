# 参考文献格式：GB/T 7714（中文论文）

> 本文件是给 AI 助手用的格式知识。**学校或期刊自己的规定永远优先**；本文件只在对方没有规定、或需要解释规定时使用。

---

## 1. 先确定用哪个版本

| 版本 | 状态 | 说明 |
| :--- | :--- | :--- |
| GB/T 7714-2015 | 已被替代，但很多学校、期刊仍在要求 | 目前网上教程和模板大多基于这一版 |
| **GB/T 7714-2025** | **自 2026-07-01 起实施**，替代 2015 版 | 官方页面：https://std.samr.gov.cn/gb/search/gbDetailed?id=4507EFE13D37CB6AE06397BE0A0A601F |

**助手规则：**
1. 用户的学校/期刊文件里写了版本号，就用那个版本。
2. 没写版本号时，先问用户，不要自己默认。
3. 用户也不知道时，说明"2025 版已实施，但不少学校仍沿用 2015 版"，建议去看最近一届的学校模板或向导师确认。

### 2025 版相对 2015 版的已知变化（只列有出处的，细则以标准原文为准）

来源：hushidong/biblatex-gb7714-2025 的 README（对标准原文的实现说明）。

- 新增**预印本**文献类型，并给出地图等示例。
- 部分文献改为按"图书""图书析出文献""期刊析出文献"等类型著录。
- 出版项和日期有变化：**非联机文献不再著录访问日期**；联机文献的日期和标点按情况有所不同；档案的形成日期按情况有所不同。
- **引入全角标点**（中文文献可使用全角标点）。

> 上面没有列出的细则（例如作者姓名大小写、"等"的阈值是否变化），本文件**没有核实**，不要凭印象回答，应让用户以标准原文或学校模板为准。

## 2. 不要手写参考文献，交给 Zotero + CSL

手写最容易出错：标点全角/半角混用、作者数截断不一致、类型标识写错。推荐做法：

1. 文献统一放进 Zotero。
2. 在 Zotero 中安装 Zotero 中文社区维护的 GB/T 7714 样式：
   - 样式站：https://zotero-chinese.com/styles/
   - 仓库：https://github.com/zotero-chinese/styles（许可证 CC BY-SA 3.0，约 6.3k star，持续维护）
   - 顺序编码制可选：`GB-T-7714—2015（顺序编码，双语）`、`GB-T-7714—2025（顺序编码，双语）`、`GB-T-7714—2025（顺序编码，双语，全角符号）` 等变体。
3. PaperFlow 写入 Word 的 `[@KEY]` 会被转成 Zotero 活引用域代码；用户在 Word 的 Zotero 插件里选好样式、点 Refresh，编号和文献表会自动生成。

**中英文混排注意**：双语样式靠文献的"语言"字段区分中英文。中文条目填 `zh-CN`，英文条目填 `en-US`（不能写"中文""English"），否则"等 / et al."会用错。

## 3. 文献类型标识（顺序编码制）

以下对应关系取自 zotero-chinese 的 `GB-T-7714—2015（顺序编码，双语）.csl` 源码（已核对）：

| 文献类型 | 标识 | 文献类型 | 标识 |
| :--- | :--- | :--- | :--- |
| 普通图书 / 专著 | M | 标准 | S |
| 会议录 / 会议论文 | C | 专利 | P |
| 期刊 / 期刊文章 | J | 数据集 | DS |
| 报纸文章 | N | 舆图（地图） | CM |
| 学位论文 | D | 档案 | A |
| 报告 | R | 软件 / 计算机程序 | CP |
| 电子公告、网页 | EB | 其他 | Z |

- 联机（网络）获取的文献再加载体标识 **OL**，例如 `[J/OL]`、`[EB/OL]`。
- **常见错误**：把"论文集中的析出文献"标成 `[A]`。那是 2005 版以前的旧写法；2015 版中 `A` 表示**档案**，析出文献要用 `//` 连接（见下文）。网上不少博客仍在用旧写法，不要照抄。

---

## 4. 作者数量规则

同一个 CSL 文件中：`et-al-min = 4`、`et-al-use-first = 3`。

即：**作者不超过 3 人全部列出；超过 3 人只列前 3 人，后面加"，等"（英文文献为", et al."）**。

## 5. 常用著录格式（2015 版，顺序编码制）

以下格式用于**检查和解释**，实际生成请交给 Zotero。

```text
期刊文章   [序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
专著       [序号] 主要责任者. 题名[M]. 出版地: 出版者, 出版年: 引文页码.
析出文献   [序号] 析出文献主要责任者. 析出文献题名[M]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 页码.
会议论文   [序号] 作者. 论文题名[C]//论文集主编. 论文集名. 出版地: 出版者, 出版年: 页码.
学位论文   [序号] 作者. 题名[D]. 保存地: 保存单位, 年份.
标准       [序号] 发布单位. 标准名称: 标准编号[S]. 出版地: 出版者, 出版年.
专利       [序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期[引用日期]. 获取和访问路径.
电子资源   [序号] 主要责任者. 题名[EB/OL]. (更新或修改日期)[引用日期]. 获取和访问路径.
```

有 DOI 时，联机文献在末尾加 `DOI: 10.xxxx/xxxx.`。**严禁编造 DOI**；查不到就不写。

---

## 6. 引用标注（正文中）

- 顺序编码制：按文献在正文中**首次出现的顺序**编号，用方括号上标，如 `…已有研究[1]`、`…[2-4]`、`…[1, 5]`。
- 同一文献再次引用沿用第一次的编号。
- 这些规则由 Zotero 自动处理；PaperFlow 离线生成的 docx 也按首次出现顺序编号（见 `paperflow/engine/zotero_field.py`）。
