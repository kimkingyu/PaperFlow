自有材料只来自这份输入，服务不作科学核验。模型不读取本地路径，不上传 PDF；大型材料请由宿主 Agent 在你的授权下另行处理。

3 · 候选关联判断与核心文献

core = 直接支撑；background = 相关背景；marginal = 边缘；irrelevant = 无关。元数据 / 摘要初筛不是正文阅读；需具体关联理由，不会伪造智能评分。

4 · 正文证据矩阵与缺口

先在「论文检索与阅读」页获取合法全文、按页阅读并保存带定位的解读，再回来刷新。提取 ≠ 理解；引用校验 ≠ 语义认证。失效哈希、unverified、摘要均不能变为已证实论据。
